# Yale: Your Next Best

Build a cheerful parody site called "Yale: The Backup Plan", an upbeat guide for "what to do if Harvard doesn't work out", treating Yale as the consolation option. Tone: sunny and gently condescending, never mean or profane.

Sections:

- Hero with a live countdown timer to The Game (hardcoded date I can edit).

- "It's going to be okay" reassurance section.

- "A Day in New Haven" itinerary as gentle satire.

- "Frequently Asked Fears" accordion.

- Shareable "encouragement" cards.

Style: warm pastel colors, rounded friendly fonts, lots of white space, like a wellness brand.

Footer: "SATIRE. A Harvard Lampoon parody. Not affiliated with Harvard or Yale."

No backend.
